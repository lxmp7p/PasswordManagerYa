# PasswordManagerYa

Клиент-серверный менеджер паролей с хранением приватных данных.

Проект состоит из:
- сервера, который отвечает за регистрацию, аутентификацию, авторизацию и хранение данных;
- CLI-клиента для доступа пользователя к своим данным;
- мигратора базы данных.

## Возможности

### Сервер

Сервер реализует:

- регистрацию пользователей;
- аутентификацию пользователей;
- авторизацию доступа к данным;
- хранение приватной информации;
- синхронизацию данных между несколькими клиентами одного пользователя;
- передачу приватных данных владельцу по запросу;
- хранение произвольных метаданных для любых записей.

Поддерживаемые типы данных:

- пары логин/пароль;
- текстовые данные;
- бинарные данные;
- данные банковских карт.

Для каждого объекта можно хранить дополнительную текстовую информацию:
- принадлежность сайту;
- описание;
- банк;
- личность;
- ...
---

## Клиент

Адрес сервера передаётся через аргумент командной строки -s.
Версию клиента можно получить через флай -v.

По умолчанию используется:

```text
https://localhost:443
```


CLI-клиент поддерживает:

- подключение к удалённому серверу;
- регистрацию пользователя;
- аутентификацию;
- получение приватных данных пользователя.

Клиент работает на:

- Linux;
- Windows;
- MacOS.

Также доступна информация о версии и дате сборки:

```bash
passwordmanager-client --version
